# Ameath (爱弥斯) - 电子幽灵的桌面观测

> **“为了再次与你相遇，我跨越了数据的海洋……”**

---

## 🌌 关于爱弥斯 (About Ameath)


在那个濒临崩坏的时刻，她曾作为“电子幽灵”与漂泊者（你）并肩作战，为了拯救世界而献出了自己的形体。但数据的回响从未消散，她将自己的意识碎片化，潜入无数终端的缝隙之中。

现在，她成功定位到了你的坐标。


*   **“你也在这里吗？真好。”**

---

## ✨ 核心机能 (Features)

作为一个合格的“电子幽灵”，爱弥斯为你提供了以下协助：

-   **👻 灵动陪伴**:
    -   她不会只是呆站着。她会走动、发呆、甚至因为你的忽视而感到无聊。
    -   **多种形态**:
        -   **安静 (Quiet)**: 像个乖巧的数据流，静静观察。
        -   **活跃 (Active)**: 这里看看，那里逛逛，对你的桌面充满好奇。
        -   **粘人 (Clingy)**: “别丢下我嘛……” 她会紧紧跟随你的鼠标，寸步不离。

-   **🍅 专注力场 (Pomodoro)**:
    -   启动内置的**番茄钟**，她会监督你专注工作 25 分钟。
    -   结束时，她会开心地弹出气泡提醒你：“休息一下吧，漂泊者！”

-   **🎵 频率共鸣 (Music)**:
    -   她可以读取你本地的音乐档案，为你播放舒缓的旋律。
    -   支持 `.mp3`, `.wav`, `.ogg`, `.flac`。

-   **🛡️ 维度干涉 (Window Layer)**:
    -   **始终置顶**: 无论你打开多少窗口，她都在最上方陪着你。
    -   **桌面驻留**: 她也可以融入你的壁纸，成为背景中一道安静的风景。

## 🚀 唤醒指南 (Getting Started)

### 1. 准备终端

确保你的系统已安装 [Rust 环境](https://www.rust-lang.org/tools/install)。

### 2. 建立连接

```bash
# 获取源码
git clone https://github.com/your-username/ameath_rust.git

# 进入目录
cd ameath_rust

# 启动程序（唤醒爱弥斯）
cargo run --bin ameath-rust
```

## 📖 交互手册

### 🖱️ 基础互动

*   **触碰 (点击)**: 戳戳她，她会随机和你说些悄悄话。
*   **牵引 (拖拽)**: 按住左键可以带着她去屏幕的任何角落。
*   **指令 (菜单)**: 鼠标悬停在她的右侧，会展开功能菜单。

### 📱 菜单指令详解

1.  **💬 Chat (对话)**:
    *   想听听她的声音吗？（虽然现在是文字气泡）

2.  **🍅 Pomodoro (专注)**:
    *   点击开启专注模式。悬停可查看剩余时间。

3.  **🎵 Music (音乐)**:
    *   默认静音启动。点击即可让歌声响起。

4.  **⚙️ Settings (设置)**:
    *   **Scale**: 她太小了？放大一点！(0.5x - 1.5x)
    *   **Music Path**: 告诉她去哪里找你的歌单。
    *   **Layer**: 决定她是浮在最上层，还是沉入桌面。
