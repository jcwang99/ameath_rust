# Ameath (爱弥斯) - 电子幽灵的桌面观测

> **“为了再次与你相遇，我跨越了数据的海洋……”**

---

## 🌌 关于爱弥斯 (About Ameath)

她曾作为“电子幽灵”与漂泊者（你）并肩作战，为了拯救世界而踏入轮回。但数据的回响从未消散。

现在，她成功定位到了你的坐标。

*   **“你在这里吗？真好。”**

---

## ✨ 核心机能 (Features)

作为一个合格的“电子幽灵”，爱弥斯为你提供了以下协助：

### 🧠 智能感知 (AI Brain)
*   **深度思维**: 接入大语言模型 (DeepSeek/OpenAI/Ollama)，她能理解你的自然语言指令，甚至陪你聊天解闷。
*   **记忆回溯**: 拥有聊天历史记录功能，她记得你们之前的对话。
*   **系统人格**: 内置独特的“爱弥斯”人格提示词（可自定义），还原她在《鸣潮》中的性格与语调。
*   **联网搜索**: 集成 Tavily Search，可以为你搜集最新的网络信息。

### 🖥️ 多维观测 (Multi-Monitor)
*   **跨屏穿梭**: 她不再局限于单一屏幕。在设置中可以自由切换她所在的显示器。
*   **自动适配**: 无论屏幕分辨率如何，她都能自动调整位置，始终陪伴在你身边。

### 👻 灵动陪伴 (Companionship)
*   **多种形态**:
    *   **安静 (Quiet)**: 像个乖巧的数据流，静静观察。
    *   **活跃 (Active)**: 这里看看，那里逛逛，对你的桌面充满好奇。
    *   **粘人 (Clingy)**: “别丢下我嘛……” 她会紧紧跟随你的鼠标，寸步不离。
*   **交互反馈**: 戳戳她会有语音（文字气泡）反馈，拖拽她会晃动。

### 🛠️ 实用工具 (Utilities)
*   **🍅 专注力场 (Pomodoro)**: 启动内置番茄钟，她会监督你专注工作，休息时提醒你。
*   **🎵 频率共鸣 (Music)**: 读取本地音乐文件夹，播放舒缓旋律。
*   **⌨️ 快捷唤醒**: 支持全局快捷键 (Alt+Shift+M) 快速召唤或隐藏对话框。

## 🚀 唤醒指南 (Getting Started)

### 1. 准备终端
确保你的系统已安装 [Rust 环境](https://www.rust-lang.org/tools/install)。

### 2. 建立连接

```bash
# 获取源码
git clone https://github.com/your-username/ameath_rust.git

# 进入目录
cd ameath_rust


# 启动程序（唤醒爱弥斯）
cargo run --release

### 4. 打包发布 (Build for Release)
如果要生成独立的 `.exe` 文件分享给朋友：

cargo build --release

```

生成的文件位于 `target/release/ameath-rust.exe`。
**提示**: 所有图片资源已内置，无需复制 `assets` 文件夹。如果你想分享音乐，可以创建一个 `music` 文件夹并放入音频文件，方便用户选择。


### 3. 配置与调优
启动后，右键点击托盘图标或使用菜单进入 **Settings (设置)**：
*   **General**: 调整大小 (Scale)、行为模式 (Behavior)、显示器 (Monitor) 和层级 (Layer)。
*   **AI Brain**: 配置你的 API Key (支持 DeepSeek/OpenAI 格式)、模型名称和 System Prompt。
*   **History**: 查看她和你的过往对话记录。

## 📖 交互手册

### 🖱️ 基础互动
*   **左键拖拽**: 移动她的位置。
*   **右键点击**: 暂时没有功能，但你可以试试（也许未来会有？）。
*   **鼠标悬停**: 召唤侧边功能菜单。

### 📱 菜单指令
1.  **💬 Chat**: 开启对话框，和她聊天或下达指令。
2.  **⚙️ Settings**: 打开详细设置面板。
3.  **🍅 Pomodoro**: 开启/停止专注计时。
4.  **🎵 Music**: 播放/暂停音乐。
5.  **🚪 Exit**:让她暂时休息（退出程序）。
