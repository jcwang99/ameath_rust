# Ameath - 互动桌面宠物

Ameath 是一个用 Rust 编写的可爱互动桌面宠物应用。它不仅能陪伴你的桌面时光，还内置了番茄钟、音乐播放器等实用功能，助你提高工作效率。

## ✨ 主要功能

*   **互动陪伴**: 可爱的像素风宠物，支持点击、拖拽和多种行为模式。
*   **专注助手**: 内置番茄钟，通过气泡提醒你劳逸结合。
*   **音乐播放**: 本地音乐播放器，支持多种音频格式。
*   **高度定制**: 支持调整大小、行为模式、音乐路径和窗口层级。
*   **轻量级**: 基于 Rust 开发，资源占用低，运行流畅。

## 🚀 快速开始

### 1. 运行应用

确保你已经安装了 [Rust 环境](https://www.rust-lang.org/tools/install)。

```bash
# 克隆仓库
git clone https://github.com/your-username/ameath_rust.git

# 进入目录
cd ameath_rust

# 运行
cargo run --bin ameath-rust
```

## 📖 使用指南

### 🖱️ 基础交互

*   **左键点击**: 与宠物互动，它会随机弹出有趣的对话气泡。
*   **左键拖拽**: 按住宠物可以将其拖动到屏幕的任意位置。松开后它会重新开始活动。
*   **右键/悬停**: 鼠标悬停在宠物右侧上方区域，会浮现**快捷菜单**。

### 📱 快捷菜单功能

当鼠标靠近宠物时，右侧会出现一排功能按钮：

1.  **💬 对话 (Chat)**:
    *   点击后宠物会弹出一个对话气泡。
    *   *(未来计划接入 AI 对话功能)*

2.  **🍅 番茄钟 (Pomodoro)**:
    *   **点击启动/停止**: 开启或关闭 25 分钟专注计时。
    *   **状态反馈**: 宠物会通过气泡提示“Pomodoro Started!”或“Pomodoro Stopped.”。
    *   **倒计时**: 鼠标悬停在该按钮上，气泡会显示当前剩余时间。

3.  **🎵 音乐 (Music)**:
    *   **点击播放/暂停**: 控制音乐的播放状态。
    *   **默认设置**: 程序启动时音乐默认处于**暂停**状态。
    *   **播放列表**: 自动循环播放选定文件夹内的所有支持文件。

4.  **⚙️ 设置 (Settings)**:
    *   打开详细的设置窗口（详见下方）。

5.  **❌ 退出 (Exit)**:
    *   完全关闭应用程序。

### ⚙️ 设置选项

点击快捷菜单中的 **⚙️** 按钮打开设置窗口。设置窗口默认**置顶**，方便随时调整。

*   **📏 缩放 (Pet Scale)**:
    *   调整宠物的大小。
    *   可选值：`0.5x` (迷你), `0.75x`, `1.0x` (标准), `1.25x`, `1.5x` (巨大)。

*   **🎭 行为模式 (Behavior Mode)**:
    *   **Quiet (安静)**: 宠物会乖乖待在原地，适合需要专注时。
    *   **Active (活跃)**: 宠物会频繁地在屏幕上左右走动。
    *   **Clingy (粘人)**: 宠物会紧紧跟随你的鼠标光标移动。

*   **📂 音乐目录 (Music Directory)**:
    *   点击路径栏选择存放音乐的文件夹。
    *   支持格式：`.mp3`, `.wav`, `.ogg`, `.flac`。

*   **📑 窗口层级 (Window Layer)**:
    *   **Always Top (始终置顶)**: 宠物永远显示在其他所有窗口的上层。适合随时互动。
        *   *特性*: 即使按下 `Win + D` 显示桌面，宠物稍微闪烁后会立即重新回到最上层。
    *   **Desktop (桌面模式)**: 宠物“贴”在壁纸上，被其他应用窗口覆盖。适合作为背景陪伴。

### 🖥️ 系统托盘

程序启动后会在任务栏右下角显示托盘图标。
*   **右键点击**: 打开托盘菜单。
    *   **Settings**: 打开设置窗口。
    *   **Quit**: 退出程序。

## 🛠️ 技术栈

本项目使用以下 Rust 生态构建：

*   **winit**: 窗口管理与事件循环。
*   **softbuffer**: 纯软件光栅化渲染 (用于设置界面)。
*   **rodio**: 音频解码与播放。
*   **tray-icon**: 系统托盘支持。
*   **windows-rs**: 调用 Windows API 实现高级窗口特性（如鼠标穿透、置顶、透明）。
*   **image**: 处理 GIF 帧动画。
